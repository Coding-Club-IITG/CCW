# Vendored font subsets

These TrueType files back the `/api/og` cover renderer.
Satori (which `next/og` uses) needs font buffers rather than CSS.

| File | Family | Weight |
| --- | --- | --- |
| `Handjet-Bold.ttf` | Handjet | 700 |
| `HankenGrotesk-Bold.ttf` | Hanken Grotesk | 700 |
| `JetBrainsMono-Regular.ttf` | JetBrains Mono | 400 |
| `JetBrainsMono-Medium.ttf` | JetBrains Mono | 500 |
